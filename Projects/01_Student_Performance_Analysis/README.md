# Student Performance Analysis

## Objective
Analyze student performance using Pandas and Matplotlib.

## Technologies
- Python
- Pandas
- Matplotlib

## Features
- Data Cleaning
- Missing Value Handling
- Average Marks Calculation
- Pass/Fail Analysis
- Topper Detection
- Data Visualization

## Visualizations
- Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot
- Box Plot
- Correlation Matrix

## How to Run

pip install -r requirements.txt

python student_analysis.py
